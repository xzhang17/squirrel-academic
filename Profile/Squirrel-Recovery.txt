学术拼音：手动备份与恢复

The public installer provides the shared Zenfire configuration and a clean
learning profile. It contains no author's private phrases or learned data.
Core features and installation instructions:
https://github.com/xzhang17/squirrel-academic-config

Manual backup

1. After changing nested dictionaries, scripts or the native customization,
   refresh the resource archive:
     /bin/bash "$HOME/Library/Rime/zenfire_profile.txt" prepare
2. Choose Squirrel > Sync user data. This also exports native learned words
   and saves zenfire_preferences.txt, including candidate usage and ordering.
3. A new installation uses ~/Squirrel-Backup/sync. Existing installations keep
   their sync_dir from installation.yaml. Keep this folder somewhere trusted;
   the private backup includes personal data. No backup schedule is installed.

Restore on a new Mac

1. Install the complete 学术拼音 package. The matching d220b92 nightly app,
   smart spacing, model and shared dictionaries are included.
2. In your private sync folder, locate the device directory containing
   zenfire_profile.txt, zenfire_profile_files.txt and zenfire_assets.zip.txt.
3. Restore into a NEW directory under an existing parent:
     /bin/bash "/path/to/sync/DEVICE/zenfire_profile.txt" restore "$HOME/Library"
   The helper prints the restored directory. It also imports a native user
   dictionary snapshot when present. Do not point restoration at a live profile.
4. Quit Squirrel before replacing ~/Library/Rime with the restored directory.
   Keep the displaced folder until the restored profile works.
5. Keep the new Mac's installation.yaml/device identity. Set sync_dir to your
   intended backup folder; do not copy another Mac's device identity.
6. Start Squirrel, choose Deploy, and test a previously learned word.

The internal schema ID is zenfire_pinyin; the public display name is 学术拼音.
The native dictionary stores learned frequencies. zenfire_preferences.txt
stores explicit preferences and the stable Chinese ranking rule. Both matter
when restoring your own candidate order. Never publish either to a public repo.

Academic subjects are selected in dicts/academic_dicts/subjects.yaml. After
editing, run /usr/bin/ruby "$HOME/Library/Rime/dicts/rebuild_academic.rb" and
choose Deploy. Source and license details are in that directory's Sources.txt.

Bracket auto completion and full-width mode are disabled. Backups stay manual.

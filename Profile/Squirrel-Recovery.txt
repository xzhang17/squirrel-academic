Squirrel academic profile on macOS

This profile was prepared for the official Squirrel nightly d220b92. New typing sessions start in English. Tap Shift for Chinese. While composing, Tab moves one syllable forward and Shift+Tab moves one syllable back. The candidate menu has seven places. Use - and = to page. With no composition, = inserts an ordinary equal sign. Press [ for the extended dictionaries and ] to return. Ctrl+P pins an eligible word. Ctrl+U removes its pin.

Add academic and daily words to their corresponding dictionaries and add exact spellings to word_shortcuts.txt. Keep account-specific phrases in custom_phrase.txt. Personal pins are stored locally in academic_preferences.txt.

From the active Squirrel menu, choose Deploy after editing. If nested Lua or dictionary files changed, run /bin/bash "$HOME/Library/Rime/academic_profile.txt" prepare before choosing Sync user data. The native backup is under ~/Squirrel-Backup/sync. To restore it, run academic_profile.txt restore "$HOME/Library" from its device folder, then swap in the restored directory with Squirrel stopped. Configure a local sync_dir in the fresh installation.yaml.

The separate SVG indicator can be installed using Mode-Indicator/Restore.command from the GitHub repository or your local backup. Either mouse button opens its menu. The A badge means English.
